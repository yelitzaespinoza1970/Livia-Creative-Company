## 📌 Project Overview

Livia Creative Company is a creative agency landing page recreated from a Figma design as part of my web development training.

The project focuses on transforming a visual design into a structured web page using HTML5 and CSS3.

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## ✨ Project Features

- Creative agency landing page layout
- Design implementation based on a Figma reference
- Navigation menu and introductory hero section
- Service cards with icons and descriptive content

## 🎯 Learning Objectives

- Practice converting Figma designs into HTML and CSS
- Improve page layout and visual styling skills
- Organize project files and assets
- Apply version control using Git and GitHub

## 👩‍💻 My Role

Recreated the provided design and developed the page structure and styling as part of my Full Stack Development training.

Completed as a front-end learning project.
